# United States Top 50 Playlist Performance and Song Popularity Trend Analysis

## Project Overview

This project focuses on analyzing the United States Top 50 music playlist to understand song popularity, chart rankings, artist dominance, and playlist performance trends.

Using Python, data analysis techniques, and interactive visualizations, this project explores how songs perform on the chart, identifies leading artists, and examines the relationship between popularity scores and playlist positions.

An interactive Streamlit dashboard has also been developed to make the analysis accessible and easy to explore.

## Project Objectives

- Analyze song popularity and playlist rankings.
- Identify the most frequently appearing songs.
- Examine artist dominance and chart performance.
- Explore popularity versus playlist ranking.
- Compare explicit and non-explicit songs.
- Analyze album types and song duration.
- Identify important playlist performance indicators.
- Build an interactive analytics dashboard.

## Technologies and Tools

- Python
- Pandas
- NumPy
- Matplotlib
